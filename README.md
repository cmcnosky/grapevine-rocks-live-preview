# Grapevine Rocks Live

[Open the website preview](https://cmcnosky.github.io/grapevine-rocks-live-preview/)

A November 2026 website concept for the Grapevine, Texas music publication. The calendar keeps the publisher and venue links with each show. The GRL TV pages link to original work. The Instagram archive indexes public post references as of November 20, 2026.

## Running the preview

Open `index.html` directly, or run `python3 -m http.server` in this directory and open the local address printed by Python. GitHub Pages serves the root of the main branch. Hash-based links open individual pages directly.

## Content

- `guide.js` contains the dated show and venue records, filters, submission review, and local demo editor.
- `media.js` holds the curated first-party profile and episode links.
- `archive-data.js` contains original Instagram post identifiers, Central dates, media formats, available tagged locations, and selected topic matches. `archive.js` provides search and pagination.
- `app.js` contains the site routes, business profiles, program directory, and practice forms.
- `assets/` contains the concept illustrations and bundled fonts with their license files.

## Preview behavior

Desk changes and show submissions belong to the current browser. Newsletter and inquiry forms demonstrate the workflow. An Instagram embed connects to Instagram when its reader is opened. Production submission handling, mailing-list delivery, authenticated administration, and billing require separate services. The dated calendar is a snapshot. The linked publishers can update their originals.

The poster and series illustrations are concept artwork. Venue and business names identify subjects of editorial coverage. Each social link opens the original publisher's material.
